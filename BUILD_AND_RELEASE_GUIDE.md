# Руководство по сборке и релизу в Google Play

Этот гайд объясняет, как открыть проект в Android Studio, протестировать его и собрать релизный пакет (`.aab`) для выгрузки в Google Play.

---

## 1. Как открыть проект в Android Studio
1. Откройте **Android Studio**.
2. В главном окне выберите **Open** (или `File -> Open`).
3. Укажите папку проекта:
   `C:\Users\Miory Cane\.gemini\antigravity\scratch\DroidIsland`
4. Дождитесь окончания синхронизации Gradle (в нижней строке статус-бара появится галочка `BUILD SUCCESSFUL`).

---

## 2. Тестовый запуск на смартфоне или эмуляторе
1. Подключите реальный Android-смартфон по USB (с включенной «Отладкой по USB» в настройках разработчика) или запустите эмулятор с камерой Punch-hole (например, Pixel 7/8).
2. Нажмите зеленую кнопку **Run (Shift + F10)** или соберите APK напрямую через терминал:
   ```bash
   ./gradlew assembleDebug
   ```
   Готовый установочный файл появится по пути: `app/build/outputs/apk/debug/app-debug.apk`.
3. Пройдите приветствие и откалибруйте положение островка под объектив камеры (доступны быстрые пресеты для камер по центру, сбоку и двойных пилюль, а также неоновый прицел).
4. Разрешите системе «Отображение поверх других приложений».

---

## 3. Быстрая сборка через командную строку (CLI)
В проекте настроен официальный Gradle Wrapper (`gradlew` и `gradlew.bat`):
- **Собрать отладочный APK:**
  ```powershell
  .\gradlew.bat assembleDebug
  ```
- **Собрать релизный App Bundle (.aab):**
  ```powershell
  .\gradlew.bat bundleRelease
  ```
- **Запустить проверку сборки:**
  ```powershell
  .\gradlew.bat check
  ```

---

## 4. Генерация релизного ключа (Keystore) и файла `.aab`
Google Play принимает приложения исключительно в формате **Android App Bundle (.aab)** с цифровой подписью разработчика:

1. В верхнем меню Android Studio выберите:
   `Build` -> `Generate Signed Bundle / APK...`
2. Выберите **Android App Bundle** -> нажмите **Next**.
3. В поле **Key store path** нажмите **Create new...**:
   - Укажите путь для сохранения ключа (например, `droidisland-release-key.jks`) в надёжное место.
   - Введите пароль для хранилища и ключа (запомните или запишите их!).
   - Заполните имя разработчика (First and Last Name).
   - Нажмите **OK**.
4. Нажмите **Next**, выберите вариант сборки **release**.
5. Поставьте галочку на оптимизации **V1 / V2 signature**.
6. Нажмите **Create**.

После сборки в правом нижнем углу появится уведомление:
`App bundle(s) generated successfully: locate`.
Файл `app-release.aab` готов для загрузки в Google Play Console!

---

## 5. Загрузка в Google Play Console
1. Войдите в свой аккаунт [Google Play Console](https://play.google.com/console).
2. Нажмите **Создать приложение** (Create app):
   - Имя: `DroidIsland`
   - Язык по умолчанию: Русский (или English)
   - Тип: Бесплатное приложение
3. В разделе **Панель управления** (Dashboard) выполните шаги:
   - Вставьте ссылку на Политику конфиденциальности (`PRIVACY_POLICY.md`).
   - Заполните анкету классификации возрастного рейтинга (все категории «Нет» -> рейтинг 3+ / Everyone).
   - Заполните анкету безопасности данных («Данные не собираются»).
   - Загрузите иконку (512x512) и описание из файла `PLAY_STORE_METADATA.md`.
4. В разделе **Рабочий выпуск (Production)** -> **Создать новый выпуск**:
   - Перетащите сгенерированный файл `app-release.aab`.
   - Нажмите **Проверить выпуск** и **Отправить на проверку**!
